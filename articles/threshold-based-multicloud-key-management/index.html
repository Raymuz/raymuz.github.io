Research overview

Organizations running workloads across cloud service providers still face a concentration of cryptographic authority when critical keys reside with one provider. This paper introduces the Benzene Ring Secure Cross-Cloud System (BRSCCS) as a proposed architecture for distributing trust across heterogeneous, cloud-native key management services.

The design applies Shamir’s Secret Sharing to a 256-bit AES master key under a 2-of-3 threshold policy. AWS Key Management Service, Microsoft Azure Key Vault and Google Cloud KMS represent separate trust domains; no single provider holds enough information to reconstruct the key.

Additional design elements include a protected confidential-computing orchestration layer, workload identity federation using short-lived credentials, and share-rotation mechanisms. These are architectural proposals described in the publication, not claims of universal production validation.

Research significance

The work examines how organizations can avoid relying on a single cloud provider for key-management authority while retaining the operational advantages of native cloud KMS services. It contributes a cross-provider security architecture intended to support stronger trust separation, vendor independence and reduced concentration risk.
