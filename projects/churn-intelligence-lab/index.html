About this project

Applied machine learning, built with transparency.

Churn Intelligence Lab is an educational and portfolio demonstration of predictive analytics and end-to-end MLOps engineering. It is not a production-validated customer decision platform. Model performance varies by dataset, and predictive scores alone should not drive customer actions.

For reviewers and collaborators: Explore the live model interface when available, inspect the training and evaluation workflow, and review the code and documentation on GitHub. The source customer datasets and private account credentials are not published on this website.
